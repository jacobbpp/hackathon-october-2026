Before the day

Please bring a personal laptop and charger. Work laptops often block the installs you'll need. Then spend ten minutes on the setup check for the tools you're likely to use.

  1. 1

    Get the repo

    Clone it, or download it as a zip if git is new to you.

    git clone https://github.com/jacobbpp/hackathon-october-2026.git
  2. 2

    Web starter (Node 20 or newer)

    npm install
npm run check
npm run install:all
  3. 3

    Notebook starter (Python 3.10 or newer)

    pip install -r notebook/requirements.txt
python notebook/check_setup.py

Each check tells you what, if anything, to fix. If you can't get it working, let the organisers know before the day and we'll help. You don't need to build anything in advance.

Challenge tiers

Every tier has somewhere easy to start and no ceiling. You don't need to finish one tier before a teammate starts the next.

1

Clean and explain

Start here

Find and fix three problems in one file.

Going further

Cleaning you can re-run from scratch, a log of every decision, and a chart where cleaning changes the story.

2

Explore and build

Start here

Add one chart or filter to a starter.

Going further

Answer the client's questions in a tool a non-technical person could use. Join files for deeper insight.

3

Predict (optional)

Start here

Run the notebook's baseline.

Going further

Beat it, show it in your tool, and say honestly how wrong it might be.

Rules of the day

AI assistants are allowed

If you can't explain it, it doesn't count. Judges may ask any team member about any part of your work.

Every decision about the data goes in the log

Dropping rows, filling gaps, merging values: write it in DATA_QUALITY_LOG.md with your reason.

Keep your cleaning repeatable

A script or notebook you can run again from scratch, not edits by hand.

Ask the coaches

They won't build it for you, but they will help you get unstuck.

Showcase and judging

5 + 3

Five minutes to demo and three minutes of questions per team. Cover the problem, what you built, what you found and what you'd do next.

Judges look for

  1. A clear definition of the problem
  2. Sensible use of data
  3. The quality and clarity of the solution
  4. Evidence of effective teamwork
  5. How well the team explains its approach

Awards

  • Best Overall Solution
  • Best Data Insight
  • Best Technical Build
  • Audience Favourite

Each member of the overall winning team receives a £50 Amazon voucher.

A focused, well-explained Tier 1 and Tier 2 beats a half-finished Tier 3.
